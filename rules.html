Platform Rules

Learn how CodeTrack works, how hints behave, and how submissions are scored.

Platform Rules

  • Solve problems independently before viewing hints or solutions.
  • Use hints to learn, not copy complete answers.
  • Progress is saved in the browser and tied to your account.
  • Do not rely on localStorage for secure authentication.

Hint Rules

  • 3 hints per day are available.
  • Hints unlock only after attempting the problem.
  • Refreshing the page does not reset the daily hint limit.
  • Hints provide guidance, not full solution code.

Problem Status

  • Todo – Not attempted yet.
  • Revision – Previously solved, recommended review.
  • Solved – Completed successfully.

Submission Rules

  • Run Code executes sample tests and shows output.
  • Submit validates all predefined test cases.
  • Accepted means all test cases passed.
  • Wrong Answer means one or more tests failed.

Progress Tracking

Solved problems, difficulty distribution, streaks, and topic progress are updated automatically after successful submissions.
